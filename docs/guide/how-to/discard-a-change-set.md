# Discard a change set

This guide shows you how to throw away a change set without saving any
of it.

## Steps

1. Open **Change sets** in the rail and select the change set. You can
   also press the discard icon in the top bar while you are working in
   it.
2. Press **Discard**. A box asks *Discard "<name>"?* and says nothing in
   it is saved and the records stay as they are.
3. Press **Discard** to confirm. Press **Keep it** to go back.

The change set moves to **Done** on the Change sets page, with the status
*Closed*. Discarding cannot be undone.
