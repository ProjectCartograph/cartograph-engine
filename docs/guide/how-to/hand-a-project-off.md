# Hand a project off

This guide shows you how to start the hand-off of a defined project to
the delivery tool. The example is the cooperative's *Quality Check
Rollout*.

## Steps

1. In the rail, choose **Projects** and select *Quality Check Rollout*.
   This opens the project record page.
2. Press **Hand off** (its tooltip reads *Hand off this project*). The
   page *Hand off Quality Check Rollout* opens. It lists the charter's
   sections, marking each *from data* or *not held in Cartograph*, and
   shows the project's state: *draft*, *defined*, *handed off*,
   *cancelled*.
3. Read the **Checks** box. *All checks pass* means nothing blocks the
   hand-off. A line saying how many block means the hand-off will be
   refused: go back to the project, open the **Checks** panel beside its
   steps, and press **Fix** on each.
4. Press **Hand off**.

If it is refused, the page shows **Handoff refused** and each problem. A
problem about a custodian has a **Fix in Data** link that opens the
project's Data step.
