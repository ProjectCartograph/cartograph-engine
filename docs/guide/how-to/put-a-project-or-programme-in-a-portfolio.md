# Put a project or programme in a portfolio

This guide shows you how to add a programme, a project or a smaller portfolio to a portfolio. The example adds the cooperative's *Market Access Programme* to the *Member Services Portfolio*.

A portfolio does not list its own contents. The programme, project or smaller portfolio says which portfolio it is in, and the portfolio's **Contents** step reads that back. For the reason, see [About portfolio decisions](../explanation/about-portfolio-decisions.md).

## Before you start

The portfolio must already exist. See [Set up a portfolio](set-up-a-portfolio.md).

## Add a programme

1. In the rail, choose **Programmes** and open *Market Access Programme*.
2. Go to the **Alignment** step.
3. Scroll to **Portfolios**. It lists the portfolios that select and fund the programme. Open the picker and choose *Member Services Portfolio*. The portfolio appears beside the ones already there.
4. Press **Merge** when you are done, then **Merge** in the box that opens.

## Add a project

1. In the rail, choose **Projects** and open the project, such as *Quality Check Rollout*.
2. On the **Context** step, find the row **Portfolios**. Press **Add** beside it. A box titled *Portfolios* opens, with the text *The portfolios that choose and fund this project.*
3. Choose the portfolio in the box.
4. Press **Merge** when you are done, then **Merge** in the box that opens.

## Add a smaller portfolio

1. Open the smaller portfolio and go to **Governance**.
2. In **Part of**, choose the larger portfolio. A portfolio cannot be part of itself, and a loop of portfolios is refused.

## Check it worked

Open the portfolio and go to its **Contents** step. The programme, project or portfolio is listed under its heading (*Programmes*, *Projects* or *Portfolios*), with a link to open it.

## If something is not as you expect

- To take something out, open it and remove the portfolio from the same field.
- You may name more than one portfolio on the same programme or project. The picker lists every portfolio in the workspace.
