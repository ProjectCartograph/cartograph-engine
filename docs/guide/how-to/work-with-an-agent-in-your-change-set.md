# Work with an agent in your change set

This guide shows you how to hand a change set to your agent and watch it
work. You need a connected agent. See [Connect an AI agent](connect-an-ai-agent.md).

## Steps

1. Work in a change set. For the cooperative, start defining *Quality
   Check Rollout*, so that the *Working in* bar names a change set.
2. Press **Agent** in the top bar. A box titled *Ask an agent to help*
   opens with a request.
3. Press **Copy**, and paste the request into your agent. The agent
   works in your change set beside you, asks you what only you can
   answer, and leaves merging to you.
4. To follow it, open **Agents at work** in the rail and press **Follow**
   beside the agent. Your view moves with it. Click anywhere to take the
   view back.
5. When it has finished, review its work. See [Review and merge a change
   set](review-and-merge-a-change-set.md).

If you have not connected an agent, the box has a **Connect** button
that opens the Agents page.
