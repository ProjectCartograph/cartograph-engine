# Export the indicators for dbt

This guide shows you how to hand your indicators to an analytics engineer
as dbt semantic layer files.

## Steps

1. In the rail, choose **Indicators**.
2. Press **dbt** (its tooltip reads *Export the KPIs for dbt*). The
   browser downloads the files.
3. Read the box that opens. It lists what the analytics engineer still
   has to decide.
4. Send the files and the list to them.

If the **dbt** button is not there, your deployment has the export off.
