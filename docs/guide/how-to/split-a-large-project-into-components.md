# Split a large project into components

This guide shows you how to take a part of a large project and give it a record of its own, so the project can list it as a component. The example is the cooperative's *Quality Check Rollout*, with a part that recalibrates the depot scales before grading starts.

## Before you start

Decide whether the part is a component or something else. Choose **Create**, then **Not sure which?**, and read the questions from the top. The first that fits decides. The one you want here reads *A component project*: it makes a change of its own that other work relies on.

If one person is in charge of the part, with the same budget as the whole, it is still a component. If it needs its own sponsor or its own budget, it is a project in a programme instead. See [About components and large projects](../explanation/about-components-and-large-projects.md).

## Steps

1. Choose **Create**, then **Not sure which?**.
2. Select **A component project**. Cartograph describes it as a project of its own, with one objective, listed as a component of each piece that depends on it.
3. Press **Start the project**. The walk opens at *What is your project about?*
4. Walk through it as you would for any [project](../tutorials/charter-your-first-project.md): describe the part in your own words and answer each question. Give it one objective, the change it exists to make.
5. When the part is saved, open *Quality Check Rollout* in **Projects**.
6. Open the **Context** step. Under **Depends on** in the **Alignment** section, press **Add**.
7. Filter by the part's name, tick its row and press **Close**.

The part now appears under **Depends on** on *Quality Check Rollout*. Each component stays its own piece of work, with its own page. Open its **Context** step and *Quality Check Rollout* is listed under **Used by**.

## If several projects need the same part

Add it as a component of each one, using steps 5 to 7. You make it once.
