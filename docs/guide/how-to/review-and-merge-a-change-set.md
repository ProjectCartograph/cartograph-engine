# Review and merge a change set

This guide shows you how to check a change set, yours or an agent's, and
merge it into the workspace. It is for the person who approves the work.

## Find it

Open **Change sets** in the rail. They are grouped as **Waiting for you**,
**In progress** (shown when there are any) and **Done**. An agent's work
shows the agent's name. Select the one to review. Your own change set is
also named in the *Working in* bar at the top, which has **Review and
merge**.

## Review it

1. At the top you see the change set's name, its status (*In progress*)
   and how many records it holds, for example *2 records*. Buttons for
   each kind, such as *Project 1*, filter the list.
2. Each record is a row: its name, *New* or *N fields changed*, and *Every
   check met* or *N open checks*. Select a row to see each field as *Was*
   and *Now*, and **Open the record** to read it in its usual screen.
3. If the change set changes a project, read **Charter as it will read**.
   Each part that differs is marked *Changed*, with added lines in green
   and removed lines struck through in red. **Show unchanged parts**
   shows the rest.
4. If you see **Decided for you**, check each choice the agent made
   without a document or your answer. **Go to the change** takes you to
   the field.
5. For what the checks mean, see [About checks](../explanation/about-checks.md).
6. If you see *Version N was saved after this started...*, ask the agent
   to update its work before you merge.

## Leave something out or send it back

- To leave a record out of this merge, clear **Include when you accept**
  on it. It stays in the change set as a draft.
- To fix a record yourself, open it and edit it. Your edit goes into the
  same change set.
- To send an agent's work back, press **Ask for changes**.

## Merge

1. Press **Merge** in the top bar, or **Merge N records** at the foot of
   the review page. A box asks *Merge N records?*.
2. If the box says *Everything is complete.*, press **Merge**.
3. If it says *Some items are unfinished.*, it lists them under each
   record in groups such as **Suggestions (3)**. Each is a link to where
   it is finished. On your own change set, write your reason under *Why
   merge before these are finished?*. **Merge anyway** stays dimmed until
   you do. Then press it. An agent's change set already carries a reason
   for each open item, so it does not ask.
4. If the box lists items under **Fix before merging**, the record cannot
   be saved as it stands. Open each link and fix the field. Merge stays
   locked until they are gone.

You see *Merged into the workspace.* If you see *A record changed since
you started. Review the change set, then merge again.*, review it again
and merge.

## If you cannot merge

An administrator may require that every check is met, that nothing is
left open, or that someone other than the author merges. If the last
applies, ask a colleague to review and merge. See [Set how changes are
controlled](set-how-changes-are-controlled.md).
