# Export the charter

This guide shows you how to save a project's charter as a PDF. The
example is the cooperative's *Quality Check Rollout*.

## Steps

1. In the rail, choose **Projects** and select *Quality Check Rollout*.
   This opens the project record page.
2. Open any of its steps, for example **Context: Alignment**.
3. Press **Charter** in the page header. Its tooltip reads *Open the
   charter this project makes*.
4. Read it. To change a part, see [Edit the charter where you read
   it](edit-the-charter-where-you-read-it.md).
5. Press **Download PDF** to save it, or **Open in a tab** to read it as
   a web page beside your work.

**Back** returns you to the project record page.
