# Set how changes are controlled

This guide shows you how to decide what a change set needs before it can
be merged. You need the **Administrator** role. The settings apply to
people and agents alike.

## Steps

1. In the rail, open **Access**. The **Change control** box is below the
   list of people.
2. Tick the rules you want:
   - **Every change goes through a change set**: saving straight to the
     record is refused.
   - **Every check is met before rolling in**: a change set with a check
     nobody met, or said why it is not met, cannot be merged.
   - **Nothing is left open before rolling in**: a change set with a
     check left open or waived cannot be merged.
   - **Someone other than its author rolls it in**: the person a change
     set is for cannot merge it.
3. Press **Merge** in the top bar. The box says *Changed in your change
   set. It takes effect once the change set is rolled in.* until you do;
   afterwards it says *In force now.*
