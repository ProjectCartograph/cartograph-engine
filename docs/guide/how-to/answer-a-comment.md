# Answer a comment

This guide shows you how to find the comments that ask you something,
answer them, and close them.

## Steps

1. In the rail, choose **Mentions**. It lists comments that ask you, by
   name or through a team you are on. It says *Nothing asks you yet.*
   when there are none.
2. Select one. It takes you to the part of the record where it was asked.
3. In the box that opens, press **Reply**, write your answer and press
   **Send**.
4. When the question is settled, press **Resolve** on the first comment
   of the thread.

To see finished threads, press **Show N resolved**. **Reopen** brings one
back.
