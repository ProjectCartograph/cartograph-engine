# Disconnect an AI agent

This guide shows you how to end an agent's access. It ends at once.

## Steps

1. In the rail, choose **Agents**.
2. Find the agent under **Connected**. Each shows when it connected, when
   it was last used and when it expires.
3. Press **Disconnect** beside it.

An administrator can switch to **Everyone's** to see and disconnect other
people's agents.
